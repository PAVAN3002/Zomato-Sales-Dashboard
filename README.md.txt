# Zomato Sales Analysis Dashboard | Excel

## Project Overview
An interactive Zomato Sales Analysis Dashboard developed using Microsoft Excel to analyze restaurant sales, customer ratings, order trends, food categories and geographical sales distribution across India.

## Dataset Information
- Dataset Type: Synthetic / AI-generated sample data
- Total Records: 280
- Geographic Coverage: 28 Indian States
- Purpose: Educational and portfolio project

## Key Performance Indicators
- Total Sales
- Average Rating
- Average Order Value
- Rating Count
- Total Orders

## Dashboard Analysis
- Monthly Sales Trend
- Daily Sales Trend
- Weekly Sales Trend
- Sales by Food Type
- Sales by State
- Quarterly Sales and Ratings
- Top 5 Cities by Sales

## Interactive Features
- Month-wise slicers
- Food category filters
- Restaurant-wise filters
- Dynamic KPI cards
- Interactive PivotCharts

## Tools and Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas
- Data Visualization

## Project Files
- `Zomato_Sales_Dashboard.xlsx` – Interactive Excel dashboard.
- `Dashboard_Screenshot.png` – Dashboard preview.

## How to Use
1. Download the Excel workbook.
2. Open it using Microsoft Excel.
3. Navigate to the Dashboard sheet.
4. Use slicers to explore sales performance.
